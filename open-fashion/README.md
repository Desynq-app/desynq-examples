**Why `flutter create .`?** The native platform folders (`android/ios/web`) are
tied to a specific Flutter version, so we don't ship them — a bundled one would
break on machines with a different Flutter (Gradle/Kotlin errors). `flutter
create .` generates them for *your* Flutter and is **safe**: it only adds the
missing native folders and **keeps your `lib/`, `assets/`, and `pubspec.yaml`
untouched**. It also runs `flutter pub get` for you.

`lib/main.dart` opens a menu that links to every generated screen.

- Screens live in `lib/fashion_app/` (or the project folder).
- Fonts load at runtime via `google_fonts` — no font files bundled.
- Images are under `assets/` and registered in `pubspec.yaml`.
